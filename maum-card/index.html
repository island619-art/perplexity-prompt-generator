✨ Gemini (AI 문구 + 나노바나나 이미지)

  2. Create API key를 눌러 키를 만들고 복사해요.
  3. AI 이미지 생성은 유료 결제 등록이 필요할 수 있어요. 예산 알림을 꼭 걸어 두세요.

📷 Pixabay (무료 사진)

  1. Pixabay 회원가입 후 로그인해요.
  2. API 문서의 "key (required)"에 있는 키를 복사해요.

🖼️ Pexels (무료 사진)

  1. Pexels 회원가입 후 로그인해요.
  2. API 신청 페이지에서 사용 목적을 적고 키를 받아요.

1

주제 고르기

1번 주제 목록에서 명언, 건강 기원, 아침 인사, 명절 인사, 생일 축하, 고객 감사 중 하나를 골라요. "✍️ 직접 입력"을 고르면 "비 오는 날"처럼 원하는 주제를 적을 수 있어요.

2

API 키 넣기 (선택)

⚙️ 설정에서 Gemini·Pixabay·Pexels 중 하나만 넣으면 사진이나 AI 그림 배경이 나와요. 키가 없어도 기본 문구와 예쁜 색 배경으로 바로 만들 수 있어요.

3

비율·줄 수·스타일 고르기

1번 목록에서 비율·줄 수·스타일을 골라요. 카톡용은 세로형 9:16이 가장 잘 맞아요. 스타일을 고르면 2번에 문구 후보 5개가 나와요. (Gemini 키가 있으면 AI가 새로 써 줘요)

4

문구 고르고 꾸미기

2번 목록에서 마음에 드는 문구를 고르면 이미지가 완성돼요. 문구를 직접 고치고, 글꼴·크기·색·위치를 바꾸고, "○○ 드림" 같은 이름도 넣을 수 있어요. 이름은 한 번 적으면 기억해요.

5

저장하고 보내기

💾 저장하기를 누르면 고화질 사진으로 저장돼요. 휴대폰에서는 💬 공유하기로 카톡·밴드에 바로 보낼 수 있어요.
